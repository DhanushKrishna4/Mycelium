A LEARNED LOCAL RULE

One cell at a time.

Mycelium is a neural cellular automata laboratory. Each cell contains sixteen numbers and perceives a 3 × 3 neighborhood. The same tiny neural network updates every cell. During inference it has no coordinates, no target image, and no global view.

Growth

Begin every training example from one seed. Learn to produce the visible pattern.

Persistence

Continue from a pool of previous states. Learn to maintain the pattern over time.

Regeneration

Damage some pooled states before training. Learn rules that may also reconstruct missing tissue.

All learning takes place locally in Python. Your browser executes the same NumPy transition through a persistent Pyodide worker. No inference service or API is involved. Erasing all living cells causes extinction until you plant a new seed.

Research foundation: Growing Neural Cellular Automata, Alexander Mordvintsev, Ettore Randazzo, Eyvind Niklasson, and Michael Levin (2020). Mycelium is an independent implementation and controlled local training case study. It makes no claim of biological realism or guaranteed repair.

Exact browser contract

32 × 32 cells, 16 float32 channels, identity and normalized Sobel perception, shared 48 → 64 → 16 update network. Hidden displays use a shared fixed scale. Pyodide 0.27.7, Python 3.12.7, NumPy 2.0.2. Exact replay is scoped to the pinned runtime; floating-point backend differences can grow over long rollouts.
