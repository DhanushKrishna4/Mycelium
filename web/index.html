Field guide / A learned local rule

The whole begins
with a neighbor.

Every cell carries sixteen numbers. It sees only its 3 × 3 neighborhood. The same tiny neural network updates every cell; together, they can grow a recognizable form.

03 / Regeneration

Return.

A rule, not a picture to copy.

During inference there are no coordinates, no target image, and no global view. The reference and live measurements help you inspect the result; they do not steer the rule. Erase every living cell and the culture stays extinct until you explicitly plant a seed.

All learning takes place locally in Python. Your browser runs the same NumPy transition in a persistent Pyodide worker. No inference service or API is involved.

Exact browser contract+

32 × 32 cells, 16 float32 channels, identity and normalized Sobel perception, shared 48 → 64 → 16 update network. Hidden displays use a fixed scale. Pyodide 0.27.7, Python 3.12.7, NumPy 2.0.2. Exact replay is scoped to the pinned runtime; floating-point backend differences can grow over long rollouts.

Research foundation: Growing Neural Cellular Automata, Alexander Mordvintsev, Ettore Randazzo, Eyvind Niklasson, and Michael Levin (2020). Mycelium is an independent implementation and local training case study. It makes no claim of biological realism or guaranteed repair.
